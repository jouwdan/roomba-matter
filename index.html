LOCAL MATTER CONTROL · EXPERIMENTAL

Your Roomba.
Locally controlled.

For newer Roombas using the Roomba Home app. Get a Matter setup code over Bluetooth, then add your compatible robot to Home Assistant, Apple Home, or Google Home.

Once paired, Matter commands and status stay on your local network, without relying on iRobot’s cloud API for that control.

Browser setup verified: Max 705 Vac & Plus 505 Combo
Both tested on firmware 9.3.6 / I3.8.149 · Test reports & compatibility
Matter-capable firmware required. Using the Roomba Home app does not guarantee Matter support. No model or firmware allowlist. Other models, Google Home and Bluefy still need testing.

This browser can’t connect to Bluetooth devices.

On a Mac, Windows PC, or Android phone, open this page in Chrome or Edge. On iPhone or iPad, use Bluefy, a browser with Bluetooth support.

Bluefy support for this helper still needs a real-device test. Safari and Firefox won’t work.

Open the HTTPS version.

Bluetooth access requires a secure page. For local development, use localhost on this computer.

1

Connect to your Roomba

Your robot should already be set up on home Wi-Fi. Keep it powered on and nearby. Close the Roomba Home app, then choose your iRobot / Roomba in the Bluetooth picker.

2

Get your Matter code

Already added to a Matter home?

Use that home’s “Share device” or pairing mode instead. Running this helper again may remove existing Matter pairings.

  1. Select Start Matter setup below.
  2. Wait for your robot to chime.
  3. Press its power button once, briefly. Your code will appear in step 3.

Keep this page open. Don’t hold the power button or factory-reset the robot.

3

Add it to your home

In your home app, choose Add Matter device or Add accessory. Enter this code manually, or scan the QR code from another screen.

Your Matter setup code and QR code will appear here after you confirm setup on the robot.

Bluetooth disconnected. Finish adding it in your home app now.

Don’t run setup again after pairing. To add a second home, share the device from the first home.

Keep this code private. It is temporary; don’t rely on it as a permanent recovery code. Home Assistant pairing and Apple Home pairing with sharing to Home Assistant have been reported; Google Home still needs testing.

Unofficial community tool. Not affiliated with iRobot or the Matter platforms.
